 Project Summary
This repository contains the logical design, Flowgorithm flowchart diagrams, pseudocode, and complete report for an adaptable school attendance tracking system. The system accepts student attendance data using a sentinel-controlled loop, calculates attendance percentages, validates inputs, and stores results in parallel arrays. Students with attendance below 85.0% are flagged for supportive intervention.

 Repository Layout
- `Report/`: Contains the complete project documentation.
- `Flowcharts/`: Contains Flowgorithm flowchart files (.fprg) and exported image diagrams.
- `Pseudocode/`: Contains language-independent pseudocode listings.
- `README.md`: Overview documentation and project repository metadata.
